# lib/

Конфигурация и тонкие обёртки над сторонними библиотеками.

Примеры будущего содержимого:

- `axios.js` — настроенный HTTP-клиент
- `swiper.js` — общая конфигурация слайдера
- `framer-motion.js` — общие варианты анимаций
- `gsap.js` — общие настройки timeline
- `highcharts.js` — базовые опции графиков

Библиотеки в эту папку не устанавливаются заранее.
Файл в `lib/` появляется только после того, как зависимость реально добавлена в проект.

Цель папки — держать vendor-конфиг в одном месте, а не размазывать его по компонентам.
