# data/

Временные и статические данные проекта, которые пока не приходят с API.

Сюда кладут:

- моки для UI
- фикстуры для локальной разработки
- статический контент до появления бэкенда

Не храните здесь бизнес-логику, константы приложения или конфигурацию сторонних библиотек.
Когда данные начнут приходить с API, соответствующий файл из `data/` обычно удаляют или заменяют вызовом из `services/`.
