# constants/

Общие константы приложения, не привязанные к конкретной фиче.

Сюда кладут:

- routes — пути маршрутов
- breakpoints — точки адаптивности
- navigation — пункты навигации
- storage keys — ключи `localStorage` / `sessionStorage`
- другие стабильные значения (лимиты, статусы, имена событий)

Константы должны быть чистыми данными без побочных эффектов и без логики.
Импортируйте через alias: `@/constants/...`.
